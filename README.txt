복리 계산기 v4
- 금액 단위 ₩ / $ 선택
- 1회 수익률 입력칸 뒤 % 표시
- 누적수익률 입력칸 뒤 % 표시
- 계산 횟수 및 누적수익률 직접 입력 기능 유지
- 통화 선택은 표시 단위 변경이며 환율 환산 기능은 아닙니다.

v5 변경사항
- 금액, 1회 수익률, 계산 횟수, 누적수익률을 입력하는 즉시 결과가 자동으로 갱신됩니다.
- 실행 버튼 기능은 그대로 유지됩니다.


v6 변경사항
- 실행 버튼을 누를 때마다 계산 횟수가 1씩 증가하고 즉시 복리 결과를 계산합니다.
- 숫자 입력 시 실시간 자동 계산 기능은 그대로 유지됩니다.


v7 변경사항
- 금액 입력란도 1,000,000처럼 천 단위 쉼표가 실시간으로 표시됩니다.


v8 변경사항
- 초기화를 눌러도 현재 입력된 금액과 ₩/$ 선택은 그대로 유지됩니다.
- 수익률, 계산 횟수, 누적수익률만 초기화됩니다.


v9 변경사항
- 원화 선택 시 금액과 결과값 아래에 달러 환산 금액을 함께 표시합니다.
- 달러 선택 시 금액과 결과값 아래에 원화 환산 금액을 함께 표시합니다.
- 인터넷 연결 시 USD/KRW 환율을 자동 확인하여 저장합니다.
- 인터넷이 없거나 환율 확인이 실패하면 마지막으로 저장된 환율을 사용합니다.
- 최초 오프라인 실행을 위한 기본 환율은 제작 시 확인한 최근 참고 환율을 포함합니다.


v10 변경사항
- 계산 결과 및 소수점이 표시되는 숫자는 최대 소수점 둘째 자리까지만 표시합니다.


v11 수정
- 계산 횟수 변경 시 누적 수익률 자동 계산 정상화
- 누적 수익률 직접 입력 시 계산 횟수/값 역산 정상화
- 원화↔달러 환산 표시 정상화
- 온라인 환율 확인 실패 시 저장된 직전 환율 사용
- 값, 환산 금액, 환율, 누적 수익률은 소수점 최대 2자리 표시


v12 변경사항
- 환율 기준을 네이버 금융 USD/KRW 매매기준율로 변경했습니다.
- 온라인에서 네이버 환율 확인에 성공하면 해당 환율을 휴대폰에 저장합니다.
- 인터넷이 없거나 네이버 환율 확인이 불가능하면 직전에 저장된 환율을 사용합니다.


v13 수정
- 네이버 HTML 화면 파싱 방식 대신 네이버 증권 JSON 환율 endpoint를 사용하도록 변경했습니다.
- 로컬 파일 실행에서 CORS 차단이 발생하는 경우 네이버 원본을 CORS 중계로 재시도합니다.
- 이전 일반 환율 캐시를 사용하지 않고 네이버 전용 저장 키로 분리했습니다.
- 최초 기본값도 현재 확인된 네이버 USD/KRW 1,380.50원으로 갱신했습니다.


v14 변경사항
- 초기화 시 금액, 통화(₩/$), 1회 수익률은 직전 입력값을 그대로 유지합니다.
- 계산 횟수와 누적 수익률만 0으로 초기화합니다.


v15 변경사항
- '값' 바로 아래에 환율 적용된 환산값을 별도 행으로 표시합니다.
- 원화 선택 시 달러 환산값, 달러 선택 시 원화 환산값을 표시합니다.
- 네이버 환율 기준 및 소수점 최대 2자리 표시를 유지합니다.


v16 변경사항
- 휴대폰에서 별도 스크롤 없이 주요 계산 화면이 한 번에 보이도록 전체 UI를 컴팩트하게 조정했습니다.
- 입력칸, 결과영역, 버튼, 환율 안내의 세로 간격과 글자 크기를 최적화했습니다.
- 작은 화면 높이에서는 자동으로 더 압축되는 반응형 레이아웃을 적용했습니다.
- 기존 계산/환율/초기화/자동실행 기능은 그대로 유지합니다.


v17 변경사항
- 홈 화면에 설치해 독립 실행할 경우 브라우저 주소창 없이 열리도록 standalone 설정을 확인/적용했습니다.
- 주소창이 사라져 확보되는 세로 공간을 활용해 계산기 UI를 이전보다 적당히 크게 조정했습니다.
- 화면을 끝까지 꽉 채우지 않고 아래쪽에 여백이 남도록 구성했습니다.
주의: ZIP 안의 index.html을 Chrome에서 content:// 주소로 직접 열면 Chrome 주소창은 웹페이지가 제거할 수 없습니다. 주소창 없이 사용하려면 HTTPS로 PWA를 설치하거나 Android 앱 형태로 실행해야 합니다.


v18 변경사항
- 이전 버전의 확대 스타일이 standalone(PWA 설치 실행)에서만 적용되던 문제를 수정했습니다.
- 이제 content:// 로 Chrome에서 직접 열어도 화면 크기 확대가 바로 적용됩니다.
- 아래쪽 여백은 남겨두고 계산기 영역만 적당히 키웠습니다.
- 단, content:// 로 Chrome에서 직접 열 때의 주소창은 웹페이지에서 제거할 수 없습니다.


v19 변경사항
- 자동실행 버튼 아래 여백에 '직전값' 버튼을 추가했습니다.
- 실행 버튼: 계산 횟수 +1
- 직전값 버튼: 계산 횟수 -1
- 계산 횟수는 0보다 작아지지 않습니다.
- 계산 횟수가 줄어들면 값과 누적수익률도 즉시 다시 계산됩니다.
